# portoweb6 — Company Portfolio

A static company portfolio landing page being rebuilt from the original Brooklyn Gilbert template into an intentional, editorial-led company presence.

## Current direction

The project is following:

- `PRD.md` for product goals, audience, sections, CTA requirements, UX and QA criteria.
- `DESIGN.MD` for layout, typography, color, imagery, motion, responsive behaviour and anti-AI-slop rules.
- `TASK.md` for the implementation sequence and progress tracking.

## Existing stack

This repository currently uses a deliberately lightweight static stack:

- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript
- Lucide Icons
- Google Fonts

There is no package manager or framework build step at the moment.

## Implementation principle

Work will be done task-by-task rather than replacing the entire site in one pass. Each task should leave the repository in a usable state and avoid introducing unnecessary dependencies.

The redesign must not preserve template artefacts simply for compatibility. Content, layout and interactions should be replaced where they conflict with the product and design brief.
