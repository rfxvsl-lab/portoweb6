# PRD — Company Portfolio Landing Page

## 1. Product
A polished company portfolio landing page built from the existing portoweb6 repository. The page should communicate credibility, selected work, services, and a clear path to contact/start a project.

## 2. Goals
- Make the company proposition immediately understandable.
- Showcase selected work without looking like a generic template.
- Provide at least 4 distinct CTAs with clear intent.
- Work cleanly across desktop, tablet, and mobile.
- Establish a reusable visual foundation for future portfolio pages.

## 3. Primary CTAs
1. View Selected Work — portfolio/projects
2. Explore Services — service details
3. Start a Project — conversion/contact
4. Contact Us — direct communication
Optional: Download Company Profile.

## 4. Audience
- Prospective clients
- Creative/technology partners
- Recruiters or collaborators
- Visitors evaluating company capability

## 5. Core Sections
1. Header/navigation
2. Hero / positioning
3. Selected work
4. Services
5. Process / how we work
6. About / credibility
7. Contact CTA
8. Footer

## 6. UX Requirements
- Clear hierarchy and scan path.
- Navigation remains understandable on mobile.
- CTA labels describe the action, not vague marketing phrases.
- Interactive elements have visible hover/focus states.
- No interaction should block access to core content.
- Respect reduced-motion preferences.

## 7. Non-goals
- No fake metrics or invented client logos.
- No excessive animations.
- No generic AI-generated illustrations.
- No gratuitous gradients, glassmorphism, blobs, or dashboard-like cards.

## 8. Success Criteria
- First viewport communicates what the company does and what visitors can do next.
- Four CTAs are visible and meaningful across the journey.
- Selected work is visually dominant without overwhelming copy.
- Layout remains coherent at mobile widths.
- Page feels authored rather than template-generated.

## 9. QA
- Desktop 1440px / 1280px
- Tablet ~768px
- Mobile 390px / 360px
- Keyboard navigation
- Focus visibility
- Reduced motion
- No horizontal overflow
- Images have meaningful alt text
