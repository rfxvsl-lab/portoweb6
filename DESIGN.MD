# DESIGN SYSTEM — Company Portfolio

## Design Direction
Editorial creative studio / modern production company. Premium, confident, restrained, tactile.

### Anti AI-Slop Rules
- No hero blob backgrounds.
- No excessive purple/blue gradients.
- No glassmorphism panels as the primary UI language.
- No floating-card-everywhere layout.
- No oversized generic AI illustrations.
- No arbitrary rounded rectangles for every section.
- Motion must support hierarchy, not decorate it.

## Layout
- Strong 12-column desktop grid.
- Generous outer margins.
- Asymmetry used intentionally.
- Section rhythm based on consistent vertical spacing.
- Full-bleed imagery can interrupt the grid to create editorial pacing.
- Mobile collapses to a clean single-column flow.

## Typography
- Use a distinctive display face for major headlines only when available.
- Use a highly legible sans/mono companion for navigation, labels, metadata and body copy.
- Strong size contrast between eyebrow, headline, body and metadata.
- Avoid excessive font weights.

## Color
Base palette should be restrained:
- Near-black / charcoal for primary surfaces.
- Warm off-white for light surfaces.
- One controlled brand accent.
- Muted neutral for metadata.
Do not introduce additional accent colors without a clear semantic reason.

## Imagery
- Prioritize real portfolio/project imagery.
- Use consistent crop logic.
- Avoid generic stock imagery where possible.
- Image treatment should feel photographic/editorial rather than tech-startup.

## Components
### Header
Minimal navigation, strong wordmark, one primary CTA.

### Hero
Large proposition, short supporting copy, primary CTA pair, optional visual anchor. Avoid centered SaaS-style hero by default.

### Work
Large featured project followed by smaller supporting projects. Metadata should be concise.

### Services
Use editorial rows/listing rather than a grid of identical cards.

### Process
Simple numbered sequence with strong typography and minimal decoration.

### About
Compact credibility statement, capabilities and selected facts only when real data exists.

### Contact
High-contrast closing section with a direct action and secondary contact route.

### Footer
Simple navigation, social/contact links, legal/copyright.

## Motion
- Subtle reveal on scroll.
- Image scale/position transitions should be restrained.
- Hover states can use underline, image crop, or small positional changes.
- Avoid constant floating/parallax effects.
- Honor prefers-reduced-motion.

## Responsive
Desktop: editorial grid and asymmetrical compositions.
Tablet: reduce column complexity.
Mobile: prioritize readability, CTA visibility, touch targets, and image crops. Never simply shrink desktop layout.

## Accessibility
- WCAG-conscious contrast.
- Keyboard-visible focus.
- Minimum comfortable touch targets.
- Semantic headings.
- Alt text for meaningful imagery.
- Reduced-motion support.

## Quality Bar
Every section must have a reason to exist. Prefer fewer, stronger elements over decorative UI. The final page should look like a designed company identity, not an AI-generated landing-page template.
